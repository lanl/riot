Sparse Physics

Sparse physics is a performance optimization distinct from the field sparsity of Section Sparsity: rather than saving memory where a material is absent, it saves work where the flow is not evolving. Large regions of many simulations are quiescent for long stretches — undisturbed ambient material, not-yet-shocked regions — and advancing them costs time without changing the solution. Sparse physics detects such regions and skips the physics update on the mesh blocks that cover them.

Method

The mechanism is built around a special sparse sentinel field, the cell delta \(\Delta\) (ccbulk::cell_delta), whose allocation on a block marks that block as active (evolving). Each stage of the time integration accumulates into \(\Delta\) a normalized measure of how much the conserved state changed over the update, summed over the state variables \(u\),

\[\Delta = \sum_{u} \frac{\left|u^{\,\text{new}} - u^{\,\text{old}}\right|} {\left|u^{\,\text{new}}\right| + 1} .\]

Where the solution is genuinely evolving, \(\Delta\) is appreciable; where the flow is quiescent, \(\Delta\) is nearly zero.

Parthenon’s sparse-field management then deallocates \(\Delta\) on any block whose values remain below the deallocation threshold, and (re)allocates it where the change would exceed the allocation threshold. Because the physics tasks build their variable packs only over the blocks on which \(\Delta\) is allocated, work is automatically confined to the active blocks: a task that finds no active blocks returns immediately, and loops over blocks visit only active ones. A quiescent block therefore carries no physics cost until activity reappears — for example, when a disturbance propagates in from an active neighbor — at which point \(\Delta\) is reallocated and the block rejoins the update.

Input Parameters

Sparse physics is controlled in the <physics> block. The threshold sets the level of relative change required to keep a block active; its default value is appropriate for most problems, and it can be loosened to deactivate more aggressively or tightened to keep marginally-evolving regions active.

Parameters in the <physics> block.

Parameter

Type

Default

Description

sparse_physics

bool

true

Skip the physics update on blocks where the flow is not evolving.

sparse_physics_threshold

Real

1e-12

Relative-change threshold \(\Delta\) must exceed for a block to remain active.

Some packages are incompatible with sparse physics and require it to be disabled (sparse_physics = false); each notes this in its own chapter.

Example

Enable sparse physics with a slightly looser activation threshold:

riot.input("physics", sparse_physics=True,
           sparse_physics_threshold=1.0e-10)
